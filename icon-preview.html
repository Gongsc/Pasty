拟物化剪贴板图标

在方案 A（剪贴板 + V）上做拟物化：真实的塑料板身、压着三张纸的钢制弹簧夹、纸叠在板面上的投影。 立体感全部由平涂色阶堆出来——硬边的明暗带、逐层加深的纸色、偏移的实心投影， 没有一个 gradient，也没有一处模糊阴影。

无渐变 · 0 个 gradientStop 托盘背景 真透明（mask 掏 V） 主色 #0067C0（沿用现有强调色） 蓝 4 阶 · 钢灰 5 阶 · 纸 3 阶

主图标

左 256px、右 128px / 48px。深底那块用来确认板身底部的深蓝厚度带在暗背景下不会糊掉。

立体感是怎么堆出来的

按绘制顺序四步。每一步只加平涂色块，靠色阶差和 1～1.5 单位的硬边偏移制造厚度与投影。

01
板身
底部露 2.5 单位深蓝当板厚，板面内再压一条顶部亮带和一条底部暗带。
02
纸叠与投影
先放一块偏移 1.5 单位的实色深蓝当投影，再叠三张纸，下层依次加深。
03
金属夹
压舌 + 三段钢面（亮顶 / 中身 / 暗底）+ 铆钉，夹口下方一条浅灰投影落在纸上。
04
品牌 V
深蓝 V 落在最上一张纸的视觉中心，避开压舌与投影带。

三级细节

拟物化撑不到 16px——铆钉、纸叠、亮带在那个尺寸只会变成脏点。所以 .ico 里放三套分别绘制的图， 不是同一张缩放。轮廓（板身矩形 + 顶部夹子）三级完全对齐，缩小时只是细节在减，形状不变。

托盘图标

托盘是单色场景，拟物化在这里没有意义也放不下：16px 单色下钢灰和蓝色都会退化成同一团。 所以托盘只取轮廓剪影，V 用 mask 掏成真透明——任务栏底色直接透上来，不是填白。 浅色 / 深色任务栏两套，Windows 不会自动反转第三方托盘图标。

确认后要交付与改动的

Pasty/Assets/Pasty.ico
256 / 128 / 64 / 48 用 L1，32 / 24 用 L2，20 / 16 用 L3。<ApplicationIcon> 指过去，同时给两个窗口调 AppWindow.SetIcon。
Pasty/Assets/Tray-light.ico
Pasty/Assets/Tray-dark.ico
各含 32 / 24 / 20 / 16，单色 + 透明缺口。非打包应用要靠 CopyToOutputDirectory 带到输出目录，运行时从磁盘读。
Services/Win32.cs
加 LoadImageW（IMAGE_ICON + LR_LOADFROMFILE），按 DPI 请求对应像素尺寸那一档。
Services/TrayIconService.cs
换掉 LoadIconW(IDI_APPLICATION)，按注册表 SystemUsesLightTheme 选浅/深色那一套，主题变化时用 NIM_MODIFY 换图标。TaskbarCreated 重建那条路径也要拿到有效句柄。
Views/MainWindow.xaml
18×18 的 LinearGradientBrush Border 换成 L3 图形，项目里最后一处渐变随之消失。
一处要一起改的注释。 TrayIconService.Remove() 现在写着「图标来自 LoadIcon(IDI_APPLICATION)，是系统共享图标，由系统自己管理生命周期」， 所以那里刻意不调 DestroyIcon。换成自己加载的 .ico 后这句话不再成立：句柄归我们， 必须 销毁，而且主题切换换图标时也要销毁旧句柄，否则每切一次主题漏一个 icon 句柄。按项目约定，注释要跟着代码一起更新。
关于「无渐变」。 拟物化通常靠渐变和模糊阴影，这一稿按你最初那条要求全部用平涂色阶替代：硬边明暗带、逐层加深的纸色、偏移实心投影。 如果你希望拟物化就上真渐变和柔和高光，说一声我加，形状不用变。
